# SQLite Clone

Building a lightweight SQLite-inspired database from scratch using C.

## Current Progress

### Stage 1: REPL

- Interactive command-line interface
- Dynamic input handling using `getline()`
- `.exit` meta-command
- Handling of unrecognized commands
- Dynamic memory allocation using `malloc()` and `free()`

## Technologies

- C
- GCC
- Git
- GitHub

## Learning Goals

This project is being built to understand how a database works internally, including:

- C pointers and memory management
- SQL parsing
- Query execution
- Serialization
- Page-based storage
- Disk persistence
- Cursors
- B-tree indexing
